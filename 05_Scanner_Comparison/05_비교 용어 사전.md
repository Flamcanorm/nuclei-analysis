# 비교 용어 사전

#전지성 #도구비교/용어

## 검사 구조

### 검사 정의

#비교용어/검사정의

보안 도구가 어떤 요청을 보내고 어떤 응답이면 결과로 인정할지 기록한 규칙이다. Nuclei의 Template, Jaeles의 Signature, WAVE의 Rule이 여기에 해당한다.

^term-scan-definition

### Target

#비교용어/Target

검사 대상이다. URL, Domain, Host, IP, Web Server, Web Page나 File 등이 Target이 될 수 있다.

^term-target

### 실행 흐름

#비교용어/실행흐름

Target이 입력된 뒤 검사 규칙 선택, 요청 실행, 결과 판정과 출력으로 이어지는 순서다.

^term-execution-flow

### Engine

#비교용어/Engine

검사 정의를 읽고 실제 요청을 실행하는 프로그램의 핵심 부분이다. 입력, 동시 실행, 속도 제한, 요청 전송과 출력 구성요소를 연결한다.

^term-engine

### Protocol

#비교용어/Protocol

컴퓨터끼리 통신할 때 따르는 규칙이다. Nuclei에서 HTTP, DNS, SSL, TCP, WHOIS 등이 서로 다른 Protocol에 해당한다.

^term-protocol

### Template

#비교용어/Template

Nuclei에서 검사 정보, 요청, Matcher와 Extractor 등을 정의하는 YAML 기반 검사 파일이다.

^term-template

### Signature

#비교용어/Signature

특정 제품이나 취약점에서 나타나는 특징과 이를 확인할 요청·조건을 기록한 규칙이다. Jaeles에서는 YAML Signature가 Web 검사를 정의한다.

^term-signature

### Rule DB

#비교용어/RuleDB

여러 취약점 검사 Rule을 모아 둔 저장소다. Rule에는 요청 경로, Parameter, Payload와 응답 판정 조건 등이 들어갈 수 있다.

^term-rule-db

### Plugin

#비교용어/Plugin

기존 프로그램에 특정 기능을 덧붙이는 별도 구성요소다. 단순 데이터가 아니라 실행 로직을 포함할 수 있다.

^term-plugin

### 공격 Pattern

#비교용어/공격Pattern

특정 취약점을 시험하기 위한 Payload와 응답에서 찾을 특징이다. Bitscanner는 발견한 Parameter에 공격 Pattern을 적용한다.

^term-attack-pattern

## 판정과 결과

### 판정 방법

#비교용어/판정방법

응답이 탐지 조건을 만족했다고 결정하는 논리다. 상태 코드, 문자열, 정규식, Header, Cookie, 응답 크기와 DSL 조건 등이 사용될 수 있다.

^term-detection-logic

### Matcher

#비교용어/Matcher

Nuclei에서 응답이 지정된 조건을 만족하는지 검사하여 탐지 여부를 정하는 구성요소다.

^term-matcher

### Extractor

#비교용어/Extractor

응답에서 Version, Token, ID, Header 값처럼 필요한 값을 꺼내는 구성요소다. 값을 추출하는 것과 취약점 여부를 판정하는 것은 서로 다른 역할이다.

^term-extractor

### Output

#비교용어/Output

프로그램이 화면이나 파일에 내보내는 결과다. 사람이 읽는 CLI 출력과 다른 프로그램이 처리할 JSONL·SARIF 등이 있다.

^term-output

## 탐색과 확장

### Crawler

#비교용어/Crawler

Web Page의 Link와 Form을 따라가며 새로운 URL과 입력 Parameter를 자동으로 찾는 구성요소다.

^term-crawler

### 확장성

#비교용어/확장성

기존 핵심 프로그램을 크게 바꾸지 않고 Template, Signature, Rule, DB나 Plugin을 추가하여 새 기능을 넣을 수 있는 성질이다.

^term-extensibility

## 자료와 평가

### 오픈소스

#비교용어/오픈소스

소스코드가 공개되고 해당 License 조건에 따라 사용·수정·배포할 수 있는 소프트웨어다. 공개되어 있다는 사실이 현재도 유지보수된다는 뜻은 아니다.

^term-open-source

### 연구 시스템

#비교용어/연구시스템

논문에서 아이디어를 검증하기 위해 설계하거나 구현한 Prototype이다. 공개 제품처럼 설치·업데이트·장기 운영할 수 있다고 자동으로 가정하면 안 된다.

^term-research-prototype

### 유지보수 상태

#비교용어/유지보수상태

오류 수정, 보안 Patch, 기능 추가와 문서 갱신이 계속 이루어지는지를 나타낸다. 저장소가 보관 처리되었다면 구조 참고에는 쓸 수 있어도 새로운 운영 환경에서 선택할 때는 위험을 검토해야 한다.

^term-maintenance

### 상위 호환

#비교용어/상위호환

새 시스템이 이전 시스템의 입력·규칙·사용법을 그대로 받아 실행하면서 추가 기능도 제공하는 관계다. 기능이 더 많다는 사실만으로 상위 호환이 되는 것은 아니다.

Jaeles Signature를 Nuclei가 그대로 실행하지 못하므로 Nuclei는 Jaeles보다 기능 범위가 넓지만 완전한 상위 호환은 아니다.

^term-upper-compatible
