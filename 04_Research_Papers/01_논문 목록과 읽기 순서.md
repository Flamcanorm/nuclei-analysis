## 첨부 파일 확인 결과

첨부 파일은 8개지만 실제 논문은 7편이다.

`정적 및 동적 분석을 이용한 크로스 체크기반 취약점 분석 기법`이 두 번 첨부되었으며, 두 파일은 마지막 줄바꿈만 다른 동일한 내용이다.

## 찾은 논문

### 1. 위험관리 기반의 비용 효율적인 실시간 웹 애플리케이션 소프트웨어 보안취약점 테스팅

- 발행연도: 2020년
- 제안 프로그램: Bitscanner
- 분야: 자동 웹 취약점 스캐너, DAST, 시그니처 기반 탐지
- Nuclei 관련성: 매우 높음

### 2. 홈페이지의 웹취약점분석모델에 관한 실증적 연구

- 발행연도: 2021년
- 저자: 박영식
- 구분: 숭실대학교 박사학위논문
- 분야: 자동·수동 점검 통합, 오탐 제거, CMS 분류
- Nuclei 관련성: 높음

### 3. 사이버 오픈소스 동적 분석의 한계를 개선한 AI 기반 보안 취약점 탐지 시스템 개발

- 발행연도: 2024년
- 저자: 우정현·고광만
- 비교 대상: OWASP ZAP
- 분야: Random Forest, SMOTE, 동적 분석, AI 취약점 탐지
- Nuclei 관련성: 매우 높음

### 4. 정적 및 동적 분석을 이용한 크로스 체크기반 취약점 분석 기법

- 발행연도: 2018년
- 저자: 송준호·김광직·고용선·박재표
- 분야: SAST·DAST 교차 검증, Exploit 재검증, 위험도 계산
- Nuclei 관련성: 높음

### 5. 웹 취약점 탐지를 위한 LSTM 기반 머신러닝과 하이브리드 애플리케이션 보안 테스트 아키텍처 제안

- 발행연도: 2026년
- 영문 제목: A Proposal of an LSTM-Based Machine Learning and Hybrid Application Security Testing Architecture for Web Vulnerability Detection
- 분야: LSTM, SAST, DAST, HAST, CI/CD
- Nuclei 관련성: 높음
- 주의: 실제 구현·성능 실험 없이 아키텍처를 제안한 연구

### 6. 웹 사이트 구조화 및 페이지별 동작크기 계산을 통한 동적 웹 취약점 점검 방법 및 절차 개선 연구

- 발행연도: 2017년
- 저자: 이재호·이상준
- 분야: 수동 동적 검사, 검사 범위, 점검자 편향, SoA
- Nuclei 관련성: 보통

### 7. 웹 애플리케이션 보안 취약점 진단 방법 개선에 관한 연구

- 발행연도: 2019년
- 저자: 유예원
- 구분: 성균관대학교 석사학위논문
- 원문 제목: 웹 애플리케이션 保安 脆弱點 診斷 方法 改善에 관한 硏究
- 분야: 수동 정적 분석, 동적 재검증, 오탐·미탐 감소
- Nuclei 관련성: 보통
