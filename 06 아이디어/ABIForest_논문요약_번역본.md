## 한국어 본문 번역·정리

### 초록

이상 탐지 문제를 해결하기 위해 어텐션 기반 격리 숲(ABIForest)이라는 새로운 Isolation Forest 변형을 제안한다. 이상 탐지 성능을 높이기 위해 Nadaraya–Watson 회귀 형태의 어텐션 메커니즘을 격리 숲에 도입한다. 핵심은 데이터 항목과 트리 자체에 따라 학습 가능한 매개변수를 이용해 각 트리 경로에 어텐션 가중치를 부여하는 것이다. 가중치와 그 매개변수를 정의하기 위해 Huber의 오염 모형을 제안한다. 그러면 어텐션 가중치가 학습 가능한 매개변수에 선형적으로 의존하며, 표준 선형 또는 이차 최적화 문제를 풀어 매개변수를 학습할 수 있다. ABIForest는 기울기 기반 알고리즘을 적용하지 않고도 간단한 방식으로 어텐션을 포함하는 최초의 Isolation Forest 변형으로 볼 수 있다. 합성·실제 데이터셋의 수치 실험에서 ABIForest는 다른 방법보다 좋은 결과를 보였다. 제안한 알고리즘의 코드도 공개했다.

**주요어:** 이상 탐지, 어텐션 메커니즘, Isolation Forest, Nadaraya–Watson 회귀, 이차계획법, 오염 모형.

## 1. 서론

새로움 또는 이상을 탐지하는 일은 중요한 머신러닝 문제이지만, 이상은 응용에 따라 달라 강한 정의가 없고 드물게 나타나므로 학습 데이터가 크게 불균형하다. 정상과 이상 사이의 경계도 정하기 어렵다[1–12]. 많은 연구에서 여러 탐지 접근법을 조사했다. 이상은 보통 정상 데이터 덩어리에서 떨어진 관측값으로 볼 수 있다. 확률·밀도 모형, 거리와 이웃, 기계학습, 격리 기반 방법 등이 사용된다.

격리 숲(iForest)은 분할 트리 여러 개에서 항목의 경로 길이를 평균내 격리 정도를 구한다. 그러나 단순 평균 대신 **Nadaraya–Watson 회귀**의 가중 평균을 쓰면 트리와 항목에 따라 유용한 경로를 더 반영할 수 있다. 각 트리의 경로 길이는 회귀의 예측값, 트리·항목별 가중치는 어텐션 가중치다. 이 가중치의 학습 매개변수를 손실 최소화로 구하되, Huber의 오염 모형을 사용하면 선형 또는 이차계획 문제로 단순화할 수 있다. 오염 모형은 기본 softmax 가중치와 학습 가능한 확률 가중치를 섞는다. L2 정규화를 더하면 이차 최적화가 된다.

논문의 기여는 (1) 어텐션을 격리 숲에 넣은 ABIForest, (2) 오염 모형과 힌지 손실을 이용한 선형·이차 최적화, (3) 합성·실제 데이터에서의 실험이다. 코드: <https://github.com/AndreyAgeev/Attention-based-isolation-forest>.

## 2. 관련 연구

**어텐션 메커니즘.** 어텐션은 모델이 중요한 입력이나 구성 요소에 더 큰 가중치를 주는 방법이다. Bahdanau 외[26]가 사용한 이후 부드러운/딱딱한 어텐션, 국소/전역 어텐션, 자기 어텐션, 다중 헤드, 계층형 어텐션 등 많은 형태가 제안되었다[18–22,28–33]. 대부분은 신경망의 일부로 구현되었고, 무작위 숲[23,34,35]이나 그래디언트 부스팅[36]에 적용한 연구도 있다.

**어텐션을 이용한 이상 탐지.** 단조 어텐션 오토인코더, 샴 네트워크, 잔차 어텐션 네트워크, 그래프 어텐션, 자기 지도 마스킹 변환기 등 다양한 방법이 제안되었다[37–44]. 그러나 기존 연구의 어텐션은 대개 신경망 구성 요소였고 숲 기반 이상 탐지 모형에 결합한 사례는 찾지 못했다.

**iForest의 확장.** 가중 iForest, EIF, 일반화 격리 숲, k-means 기반 iForest, 퍼지 집합 기반 방법, 확률적 방법, 유사도 기반 방법, 커널 격리 숲, 기능적 격리 숲, 심층 격리 숲 등 여러 변형이 있다[45–56]. 이들 역시 iForest에 어텐션을 넣는 접근은 아니다.

## 3. 예비 개념

### 3.1. Nadaraya–Watson 회귀로 보는 어텐션

입력 `xᵢ`와 출력 `yᵢ`의 자료에서 새 입력 `x`의 출력을 추정할 때 단순 평균 `(1/n)Σᵢyᵢ` 대신 관련성에 따른 가중 평균을 쓴다.

```text
ŷ(x) = Σᵢ α(x, xᵢ) yᵢ                                      (1)
α(x, xᵢ) = K(x, xᵢ) / Σⱼ K(x, xⱼ)                         (2)
가우시안 커널의 경우 α(x, xᵢ) = softmax(−||x−xᵢ||²/ω)  (3)
```

`x`와 `xᵢ`가 가까울수록 가중치가 높아진다. 어텐션의 언어에서는 새 입력 `x`가 **질의(query)**, 비교할 입력 `xᵢ`가 **키(key)**, 출력 `yᵢ`가 **값(value)**, `α`가 **어텐션 가중치**다. 가중치에 학습 가능한 매개변수를 넣을 수도 있다.

### 3.2. 격리 숲

데이터셋 `D`에서 무작위 부분집합을 뽑고, 특징 `q`와 그 범위 안의 분할값 `p`를 무작위로 선택해 좌·우로 나눈다. 데이터 하나만 남거나 최대 깊이에 이르기까지 재귀적으로 분할하고, 새 부분집합에서 다음 트리를 만든다. `T`개의 트리가 만들어지면 학습이 끝난다. 트리 `k`에서 항목 `x`가 잎까지 가는 경로 길이가 `hₖ(x)`다. 이상은 보통 밀집된 정상 데이터보다 짧은 경로에서 분리된다.

```text
E[h(x)] = (1/T) Σₖ₌₁ᵀ hₖ(x)
s(x,n) = 2^[−E(h(x))/c(n)]                               (4)
c(n) = 2H(n−1) − 2(n−1)/n                                 (5)
```

`H(n) ≈ ln(n)+0.577216`이다. 점수 `s`가 1에 가까울수록 이상일 가능성이 높다. 원래 iForest는 결정 임계값 `τ = 0.5`를 쓴다.

## 4. 어텐션 기반 격리 숲

기존의 단순 평균은 데이터 항목과 특정 격리 트리의 관계나 트리 간 차이를 반영하지 않는다. ABIForest는 각 트리 경로에 가중치를 둔다.

### 4.1. iForest의 질의, 키, 값

트리 `k`의 출력 `hₖ(x)`가 어텐션의 **값**이다. 새 항목 `x`와 같은 잎에 들어간 학습 항목들의 평균 벡터 `Aₖ(x)`를 **키**로, `x`를 **질의**로 정의한다. 새 항목이 잎의 다른 항목들과 가까우면 그 트리가 이를 잘 표현한다고 볼 수 있다.

```text
Aₖ(x) = 같은 잎에 들어간 학습 항목들의 평균              (7)
E[h(x)] = Σₖ₌₁ᵀ α(x, Aₖ(x), w) hₖ(x)                     (8)
Σₖ α(x, Aₖ(x), w) = 1,   α ≥ 0                           (9)
```

`w`는 데이터와 트리 특성에 따라 학습하는 어텐션 매개변수다. 손실 `L`을 최소화하여 `w`를 구한다(식 10). 그림 1은 각 트리의 키·경로 길이·어텐션 가중치를 곱해 더하고 임계값과 비교하는 과정을 보여준다.

**그림 1.** iForest에 어텐션을 결합한 ABIForest의 일반 구조.

### 4.2. 손실 함수와 어텐션 가중치

경로 길이 임계값 `γ = −c(n)log₂(τ)`를 정한다(식 11). `E[h(x)] ≤ γ`이면 이상, 그렇지 않으면 정상이다(식 12). 학습 항목의 레이블 `yₛ`는 이상일 때 1, 정상일 때 −1이다. 논문은 예측의 경계 위반을 벌점으로 주는 힌지 손실을 쓴다.

```text
L = max(0, yₛ(E[h(xₛ)]−γ))                               (13)
w* = argmin_w Σₛ max(0, yₛ(Σₖ α(xₛ,Aₖ(xₛ),w)hₖ(xₛ)−γ)) (14)
```

예측과 실제 레이블이 맞으면 손실은 0이다. 레이블이 없으면 원래 iForest의 결과를 임시 레이블로 쓸 수 있지만, 틀린 임시 레이블은 후속 학습을 해칠 수 있다.

### 4.3. Huber의 오염 모형

기본 확률분포 `P`와 임의의 확률분포 `R`을 오염 정도 `ε ∈ [0,1]`로 혼합한다.

```text
F = (1−ε)P + εR                                           (15)
pₖ = softmax(−||x−Aₖ(x)||²/ω)                           (16)
R = w = (w₁,…,wₜ)
αₖ = (1−ε)pₖ + εwₖ                                      (17)
```

`ε=0`이면 기본 softmax만, `ε=1`이면 학습 가능한 분포만 남는다. `wₖ ≥ 0`이고 가중치 합은 1이다. 중요한 점은 `αₖ`가 학습 매개변수 `wₖ`에 선형으로 의존한다는 것이다.

### 4.4. 오염 모형을 이용한 손실

식 17을 힌지 손실에 넣으면 고정된 softmax 부분과 `wₖ`에 선형인 부분으로 나뉜다(식 18–19). 보조 변수 `vₛ`를 도입하면 `Σₛ vₛ`를 최소화하는 선형계획 문제로 바꿀 수 있다(식 20–24). `λ||w||²`를 정규화항으로 추가하면 다음의 이차계획 문제가 된다.

```text
minimize  Σₛ vₛ + λ||w||²                               (25)
subject to 각 항목의 힌지 손실 조건, vₛ ≥ 0,
           w₁+…+wₜ = 1, wₖ ≥ 0
```

이렇게 하면 신경망의 기울기 기반 최적화 없이 어텐션을 학습할 수 있다.

**그림 4.** Circle에서 `ω`와 `ε`에 따른 F1. **그림 5.** Circle에서 `ε`와 트리 수에 따른 F1. **그림 6.** Circle 시험 데이터와 두 방법의 예측. **그림 7–9.** Normal 데이터에서 매개변수별 F1과 예측 비교.

### 5.2. 실제 데이터셋

Mulcross는 밀집한 이상 군집 두 개를 포함하는 다변량 정규분포 합성 자료이며, Http는 원래 iForest 연구에 사용된 네트워크 자료다. Pima는 당뇨 여부를 예측하는 자료다. Credit, Mulcross, Http는 실험을 단순화하려고 크기를 줄였다.

## 6. 결론

ABIForest의 장점은 (1) 어텐션 신경망의 역전파 대신 표준 이차 최적화로 가중치를 학습한다는 점, (2) 다른 커널·오염 모형·트리 부분집합·경로 분기 가중치·다중 헤드 어텐션 등으로 확장하기 쉽다는 점, (3) 숲을 만든 뒤 어텐션을 학습하므로 매개변수를 바꿀 때 숲을 다시 만들 필요가 없다는 점, (4) 높은 가중치를 얻은 격리 트리를 살펴보면 이상 판정의 이유를 일부 해석할 수 있다는 점, (5) 표형 데이터를 다루며 여러 데이터에서 iForest의 성능을 높였다는 점이다.

한계는 오염 비율 `ε`, softmax 매개변수 `ω`, 정규화 `λ` 등 추가 설정값 때문에 검증 시간이 늘고 최적화 계산도 필요하다는 점이다. 무엇보다 이 논문의 ABIForest는 최적화 기준을 만들 **정상·이상 레이블을 요구하는 지도 모형**이다. 일부 실제 데이터에서는 개선 폭이 작지만 원래 iForest가 놓친 이상을 더 찾아냈다. IForest의 임시 예측을 레이블로 사용하면 틀린 예측이 ABIForest의 학습을 해칠 수 있으므로 이를 어떻게 처리할지 향후 연구가 필요하다.
