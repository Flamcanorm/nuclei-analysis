# 이상 탐지와 멀티뷰 학습: 논문 7편 이해 가이드

## 먼저 읽는 핵심

이 자료에는 앞서 정리한 **Isolation Forest 심층 연구**와 새로 받은 PDF 여섯 편을 함께 다룬다. 일곱 편은 같은 문제를 푸는 논문이 아니다. 멀티뷰 논문은 여러 종류의 정보를 결합하는 방법을 정리한 **리뷰**이고, 나머지는 서로 다른 데이터·환경에서 이상을 찾거나 Isolation Forest를 바꾸는 연구다.

이상 탐지의 기본 질문은 **“대부분과 다른 데이터를 어떻게 찾을까?”**다. 데이터에 정상·이상 정답이 충분하지 않은 경우가 많아서, 정상 패턴에서 벗어남을 수치로 표현하는 *이상 점수*가 중요하다. Isolation Forest(IForest)는 데이터를 무작위로 분할하는 트리에서 **빨리 분리되는 데이터가 이상일 가능성이 높다**는 생각을 쓴다. 그러나 *빨리 분리된다*는 기준은 전역적으로 희소한 데이터에 강하며, 정상 집단 안에 숨어 있는 국소 이상이나 특정 데이터 분포에는 약할 수 있다. 또한 사용하는 트리·표본·임계값에 따라 결과가 바뀐다.

## 각 논문의 해결 과정을 차례로 이해하기

### 1. 멀티뷰 리뷰: “하나의 대상을 여러 관점으로 보기”

한 사람의 행동을 영상만으로 보면 자세는 알 수 있지만 소리나 시간적 움직임의 정보가 부족할 수 있다. **뷰(view)**는 같은 대상을 설명하는 서로 다른 특징 집합 또는 데이터 원천이다. 영상·음성, 문서 본문·저자, 웹 로그의 요청 경로·사용자 에이전트처럼 나눌 수 있다. 논문은 여러 뷰를 원자료에서 결합하는 방식, 뷰별 분류 결과를 결합하는 방식, 뷰별 표현을 배운 뒤 합치는 방식을 구분한다. 딥러닝에서는 CNN이 국소 공간 패턴, RNN이 시간 순서, RBM·오토인코더·GAN이 잠재 표현 또는 생성 관계를 학습하는 예를 보여준다. **이 리뷰만으로 특정 이상 탐지 알고리즘의 정확도가 검증된 것은 아니다.**

### 2. IForest와 MVIForest: “얼마나 빨리 떨어져 나오는가”

IForest는 여러 격리 트리(isolation tree)를 만든다. 트리의 각 노드에서 임의의 특징과 분할값을 골라 데이터를 나눈다. 남들과 동떨어진 점은 보통 적은 분할만으로 혼자 남는다. 여러 트리에서 얻은 **경로 길이**가 짧을수록 이상 점수를 높게 준다. 여기서 표본 크기 `ψ`는 트리 하나를 만들 때 뽑는 데이터 수, `t`는 트리 수, **결정 임계값**은 점수부터 이상으로 부를지의 기준이다. 논문은 세 값에 단일한 최적 답이 없음을 보인다. MVIForest는 트리를 차례로 판단해 과반수가 정해지면 남은 트리를 보지 않는다. 따라서 주로 **추론 절차의 시간**을 줄인다. EIF는 분할 방향을 바꿔 축 평행 분할의 인공적인 영역을 줄이는 별도의 방법이다.

### 3. EPICS 엣지 논문: “이상 판단을 센서 가까이에서”

**PV(Process Variable)**는 온도, 모터 위치처럼 제어 시스템에서 이름을 붙여 공개하는 값이다. **IOC(Input/Output Controller)**는 장치값을 읽고 PV를 제공하는 제어기다. 이 논문은 PV 여러 개의 최근 측정치를 **슬라이딩 윈도**로 모아 엣지에서 판단한다. 오토인코더는 정상 윈도를 재구성해 복원 오차가 큰 경우 경보를 낸다. IF는 윈도에서 평균·표준편차·최댓값·왜도 같은 특징을 뽑아 격리 용이성을 본다. **양자화**는 신경망의 수치를 작은 정수 표현으로 바꿔 저장 공간과 계산 부담을 낮춘다. 결과를 새로운 경보 PV로 내보내므로 기존 EPICS 화면과 경보 도구가 그대로 받을 수 있다. 이 연구의 대상은 10–100Hz의 중간 속도 스트림과 실험실 테스트베드이며, 초고속 장기 운영 성능까지 검증한 것은 아니다.

### 4. 웹 트래픽 논문: “로그를 모델이 읽을 수 있는 수치로”

웹 로그에는 요청 방식, URI, 상태 코드, 전송 바이트, 사용자 에이전트 같은 문자열과 숫자가 섞여 있다. 이 연구는 결측 행을 제거하고 범주형 값을 **원핫 인코딩**하며 수치값을 **표준화**했다. URI 발생 횟수, 침해 지표(IOC) 발생 횟수, 사용자 에이전트 발생 횟수, URI 길이 같은 파생 특징을 추가했다. IForest 학습은 비지도이지만 시험 결과는 사람이 붙인 정상·이상 레이블과 비교했다. 따라서 **비지도 학습**과 **레이블을 사용한 평가**를 구분해야 한다. 보고된 수치는 그 웹 로그와 처리 절차에서 얻은 것으로 다른 네트워크에 그대로 보장되지 않는다.

### 5. ABIForest: “트리마다 다른 신뢰도 부여”

일반 IForest는 트리 경로를 평균낸다. ABIForest는 각 항목을 판별할 때 더 유용한 트리 경로에 큰 **어텐션 가중치**를 준다. **Nadaraya–Watson 회귀**는 유사한 관측치에 높은 가중치를 주어 값을 추정하는 커널 방법이다. 이 논문은 이를 어텐션 형태로 이용한다. **Huber 오염 모형**은 데이터의 일부가 정상 분포와 다른 오염 성분이라고 가정한다. 가중치의 학습은 신경망의 역전파가 아니라 선형 또는 이차 최적화로 풀 수 있다. 다만 최적화 기준을 만들 정상·이상 레이블이 필요하고, 오염 비율 등 추가 매개변수도 조정해야 한다. 그러므로 레이블 없는 IF를 그대로 대체하는 방식으로 생각하면 안 된다.

### 6. X-iForest: “첫 후보를 다시 걸러 내기”

네트워크에서 실제 이상 비율을 모르는데 IF의 `contamination` 비율을 잘못 지정하면 성능이 흔들릴 수 있다. X-iForest는 IF의 탐지 결과에서 정상 군집 중심과 의심 지점 사이의 표준 유클리드 거리를 보고 **X-means** 군집화로 다시 선별한다. X-means는 k-means의 군집 수를 미리 고정하기 어려울 때 군집 수를 탐색하는 확장이다. 여기서 **2차 선별**은 IF가 표시한 후보를 그대로 확정하지 않고 군집 구조를 이용해 점검하는 단계다. 이 논문의 높은 ADR은 평가에 사용한 8개 데이터셋과 비교 방법의 조건에서 얻은 결과다.

### 7. ISER: “초구의 크기로 국소 밀도를 표현하기”

**초구(hypersphere)**는 2차원에서는 원, 3차원에서는 구, 그 이상의 차원에서는 같은 거리 조건으로 정의되는 영역이다. 무작위로 고른 중심에서 가장 가까운 이웃까지의 거리를 반지름으로 삼으면, 빽빽한 곳에서는 반지름이 작고 성긴 곳에서는 크다. ISER는 이 반지름을 **국소 밀도의 단조 변환**으로 해석한다. 여러 번 만든 초구 앙상블에서 데이터가 어떻게 덮이는지를 표현하고, 평균 기반 또는 이론적 이상 참조 패턴과의 **유사도 기반 점수**로 이상을 찾는다. 국소 이상은 전체에서는 흔해 보여도 자신의 주변 집단과 비교하면 다를 수 있다. ISER는 이런 차이를 포착하려 한다. 논문은 데이터 크기 `n`에 대해 선형 시간과 일정한 공간 요구량을 주장하며, ISER 표현을 IForest에 결합한 ISER-IF도 평가한다.

## 자주 나오는 용어

| 용어 | 뜻 | 이 자료에서 기억할 점 |
|---|---|---|
| 이상(anomaly), 이상치(outlier) | 다른 데이터의 일반적인 패턴과 다른 관측값 | “이상”이 곧 공격이나 고장이라는 뜻은 아니다. |
| 비지도 학습 | 학습에 정답 레이블을 쓰지 않음 | 성능 평가에는 레이블을 쓸 수 있다. |
| 지도 학습 | 정답 레이블을 이용해 모형 또는 가중치를 학습함 | 이 논문의 ABIForest는 지도 방식이다. |
| 특징(feature) | 모형에 제공하는 측정값 또는 파생값 | 웹 로그의 URI 길이, PV 윈도의 평균 등이 예다. |
| 뷰(view) | 같은 대상을 보는 하나의 데이터 관점 | 특징 한 개와 항상 같은 뜻은 아니다. |
| 앙상블 | 여러 모델이나 여러 분할의 결과를 결합함 | IF의 여러 트리, ISER의 여러 초구 분할이 해당한다. |
| 이상 점수 | 이상일 정도를 나타내는 연속적인 수치 | 점수가 높을수록 이상이라는 정의는 모델마다 확인해야 한다. |
| 임계값(threshold) | 점수를 정상·이상 판단으로 바꾸는 기준 | 바꾸면 재현율과 오경보율이 함께 변한다. |
| 오경보(FP) | 정상을 이상으로 잘못 판단함 | 운영자가 불필요하게 대응해야 한다. |
| 미탐지(FN) | 이상을 정상으로 놓침 | 보안·안전 환경에서는 피해가 클 수 있다. |
| 정밀도 | 이상이라고 한 것 중 실제 이상인 비율, `TP/(TP+FP)` | 오경보가 많으면 낮아진다. |
| 재현율/탐지율 | 실제 이상 중 찾아낸 비율, `TP/(TP+FN)` | 미탐지가 많으면 낮아진다. |
| 특이도 | 실제 정상 중 정상으로 분류한 비율, `TN/(TN+FP)` | 오경보율은 일반적으로 `1−특이도`다. |
| F1 점수 | 정밀도와 재현율의 조화평균 | 둘 중 하나가 낮으면 크게 낮아진다. |
| ROC AUC | 임계값을 바꾸며 얻는 ROC 곡선 아래 면적 | 1에 가까울수록 대체로 분리 능력이 좋다. |
| ADR | 이상 탐지율(Anomaly Detection Rate) | 문헌마다 계산 정의를 확인해야 한다. |
| 개념 변동(concept drift) | 시간이 지나 정상 데이터의 패턴이 달라짐 | 센서와 네트워크의 장기 운영에서 중요하다. |
| 스왐핑(swamping) | 정상 데이터가 이상처럼 보이는 현상 | 오경보와 관련된다. |
| 마스킹(masking) | 이상들이 서로 뭉쳐 정상처럼 보이는 현상 | 실제 이상을 놓칠 수 있다. |

## 숫자를 비교할 때 주의할 점

논문 사이의 정확도·AUC·F1 숫자를 한 줄로 나열해 순위를 매길 수는 없다. **데이터셋, 이상 비율, 레이블 기준, 특징 설계, 임계값, 하드웨어**가 다르다. 예를 들어 웹 로그 논문의 정확도 93%와 EPICS 논문의 F1 0.905는 서로 다른 문제·지표다. 또한 멀티뷰 리뷰는 성능 경쟁 실험이 아니라 방법을 정리한 문헌 연구다. ABIForest는 레이블을 요구하는 반면 기본 IF·ISER는 비지도 이상 탐지에 초점을 둔다.

EPICS 논문 PDF의 첫쪽에는 저자가 **Ravi Dayani**로 적혀 있지만 이후 쪽의 머리말에는 **Selvakumar Kalyanasundaram**이라는 다른 이름이 나온다. 이 서지 정보 불일치는 PDF 원문에 있는 그대로이며, 저자 표기는 첫쪽의 논문 제목 아래에 있는 이름을 따랐다.
